# TruePrice

Track real Amazon price history while you browse.

TruePrice is a lightweight Chrome/Brave/Edge extension that captures the current product price and turns it into a clear, readable history—so you can make a decision based on real data, not vibes.

## Why TruePrice

- **Instant context**: See where today’s price sits compared to recent highs/lows.\n+- **Clean visuals**: Hover any point to see the exact date + price.\n+- **A real dashboard**: All tracked products in one place with mini-charts and one-click “Open on Amazon”.\n+- **Fast + minimal**: Simple architecture, no heavy UI frameworks, no bloat.\n+
